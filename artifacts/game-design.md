# RUNAWAY CITY — 설계 문서

참고한 게임: FFX Runner(Officine Pixel, 2004 — 노란 차로 들이받는 차들에게서 도망), GTA 시리즈의 별 수배 시스템,
Need for Speed: Most Wanted(2005)의 추격 단계·로드블록·스파이크, Smashy Road / Escape Road류 생존형 추격 게임.

## 디자인 브리프
- **플레이어 약속**: 밤의 도심에서 끝없이 늘어나는 경찰을 따돌리며 최대한 오래 살아남는다.
- **목표 감정**: 아슬아슬함 → 압박 → "한 판만 더".
- **주 동사**: 운전(가속/조향). **보조 동사**: 핸드브레이크 드리프트, 니트로, 점프대, 아이템 줍기.
- **5~30초 반복**: 골목·교차로 선택, 경찰 들이받기 피하기, 경찰끼리/벽에 충돌 유도.
- **1~5분 변화**: 수배 별 1→5. 순찰차 → 인터셉터 → 헬기 서치라이트 → SWAT 트럭·로드블록·스파이크 → 장갑차·헬기 2대.
- **패배/재시작**: 차량 내구도 0(WRECKED) 또는 멈춘 채 포위(BUSTED). R/Enter로 즉시 재시작.
- **보상/위험**: 현금(점수), 렌치(수리), 니트로. 위험한 도로 한복판·좁은 터널에 배치.
- **잘하는 플레이어**: 경찰을 기둥/벽/다른 경찰에 부딪히게 만들어 격파(+점수, +수배도), 터널·고가도로·다리를 활용해 시야를 끊음.
- **비목표**: 하차, 무기, 스토리, 오픈월드 미션.

## 코어 루프 계약
플레이어는 **운전**해서 **오래 생존하고 점수를 모으며**, **늘어나는 경찰 추격(수배 별)**이 위험을 만든다.
성공 → 점수·현금·격파 보너스, 수리·니트로 획득. 실패 → BUSTED/WRECKED 화면, 기록 표시 후 즉시 재도전.

## 맵 계획 (13×13 격자 도심, 블록 간격 60m, 약 730m 사방)
- **고가도로 A/B**: 동서(z=-120, 10m)·남북(x=120, 16m) 고가가 입체 교차. 아래 도로는 기둥 사이로 달리는 "다리 아랫길".
- **원형 교차로 4곳**: 섬을 돌아 나가는 교차로, AI도 섬을 우회.
- **주차장**: 주차된 차 사이 통로.
- **강과 다리**: x=-210 남북 운하. 다리는 5곳뿐 → 강변도로에서 경로 선택이 중요.
- **터널**: 북동쪽 언덕을 관통하는 180m 터널(z=180). 언덕이 시야를 막아 헬기 외엔 추적이 끊김.
- **광장**: 중앙 광장, 분수, 점프대 2개. **공원**: 나무 사이 지름길. **골목**: 일부 블록에 좁은 골목.
- 시작: 광장 근처 도로, 순찰차 2대가 뒤에서 출발(첫 10초 안에 첫 위협).
- 단계 상승: 시간(초당 +1) + 격파(+12). ★2 30, ★3 70, ★4 120, ★5 180.
- 회복 구간: 단계 상승 직후 아이템 재배치, 알림으로 다음 위협 예고.
